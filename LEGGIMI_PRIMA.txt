COME AGGIORNARE IL SITO GITHUB
1. Estrai questo ZIP.
2. Apri il repository "jali" su GitHub.
3. Carica TUTTI i file e le cartelle nella RADICE del repository.
4. Sostituisci i vecchi file quando GitHub lo richiede.
5. Nella radice devono vedersi:
   index.html
   style.css
   app.js
   battlefield.html
   game-shell.css
   games/
   downloads/
   .nojekyll
6. Aspetta il completamento di GitHub Pages.
7. Apri:
   https://alessiafrustagli-sudo.github.io/jali/
8. Fai CTRL + F5.
